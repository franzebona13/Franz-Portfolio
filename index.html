02How I work

From idea to
working system

A simple, repeatable way of working that keeps every build — circuit or code — clear, tested, and easy to improve.

  1. 01

    Understand

    Break the problem down into requirements, inputs, outputs, and constraints.

  2. 02

    Design

    Truth tables, schematics, and wireframes — planned before anything gets built.

  3. 03

    Build

    Wire it on the breadboard or write the code, one working piece at a time.

  4. 04

    Test & refine

    Measure, debug, and iterate until it behaves exactly as designed.

04Projects

Selected work
and builds

A mix of Arduino systems, digital logic circuits, and web applications. Open any project to see its photos and demo videos.

Hardware · Electromechanical

An automated electromechanical arm that replicates the functions of a human arm through joints, actuators, and a control system — for tasks like material handling, assembly, and sorting.

Hardware · Arduino · Servos

A ball navigates a maze as the platform tilts to simulate gravity changes — controlled with an Arduino, servo motors, and a UI controller, with an ultrasonic sensor detecting the finish point.

Software · HTML · CSS · JS

An interactive number-guessing web game that generates a random number and gives instant feedback on every guess, with a clean, responsive layout.

Software · Web app

A web-based inventory management app built with HTML, CSS, and JavaScript.

Hardware · Arduino · Sensors

An Arduino-based robot integrating an ultrasonic sensor, IR sensors, and a servo motor to detect obstacles and follow a predefined line, adjusting its movement automatically.

Hardware · Arduino · Keypad

A secure Arduino-powered lock that grants access only when the correct combination is entered on a keypad.

Hardware · Arduino · LED matrix

A music-reactive LED device that uses a microphone and an Arduino to display sound levels in real time.

Hardware · 555 Timer · CD4017

A 555 timer in astable mode generates clock pulses that a CD4017 decade counter uses to light LEDs in sequence.

Hardware · Analog audio

An amplifier circuit that boosts an audio signal, which is then output through a speaker.

Hardware · Light sensing

A device that automatically turns on when there is no ambient light.

Digital logic · Sequential

Four 74HC73 JK flip-flops configured as a 4-bit binary counter that cycles 0000–1001, with a reset circuit that clears the count back to 0 — output shown on LEDs.

Digital logic · Combinational

A combinational circuit that adds two 2-bit binary numbers at once using XOR, AND, and OR gates, with the sum and carry-out displayed on LEDs.

Digital logic · Display

Displays digits 0–9 by lighting the right combination of segments (a–g) — the same technique used in clocks, calculators, and meters.

Digital logic · Universal gates

Boolean functions implemented with only NAND or NOR gates — universal gates that can perform AND, OR, and NOT, simplifying the design.

Digital logic · Boolean

A logical expression realized by interconnecting AND, OR, and NOT gates to process binary inputs and produce the correct output.

Digital logic · Boolean

Reducing a logic expression to its simplest form without changing its output — making the circuit easier, faster, and more efficient.

Digital logic · SOP / POS

Sum of Minterms (SOP) is an OR of AND terms that produce an output of 1; Product of Maxterms (POS) is an AND of OR terms that produce an output of 0.

Digital logic · SOP / POS

The same SOP/POS principles applied to a different Boolean expression.

Transistor logic · DTL

DTL circuits combine diodes and a transistor to perform basic logic functions.

Transistor logic · RTL

RTL circuits perform digital logic using resistors, with a transistor providing output amplification.
